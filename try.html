Try Nifla

Write any Nifla program and run it right here. The checker reads it first — if something is provably wrong, it refuses in plain words before anything runs, and tells you how to fix it.

The program's arguments are the words Ada and Byron, the same words the lessons use. Each run starts with fresh, empty papers.

The whole hosted language — and the floor desk, for floor blocks.

Nifla is a public-domain programming language by Tyler Kovalevich — programmed like JavaScript, runs like Swift, all the way down to an operating system. The language, this site, and everything on it are given away freely.

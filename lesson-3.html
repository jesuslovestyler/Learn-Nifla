Lesson 3 — Keeping many things

Step 1: a row of values, reached by number

Real programs rarely keep one thing; they keep rows of things. A list is a row of values between [ ], separated by commas. Items are numbered from 0 — the first item is list[0] — and list[i] reaches one item. Here is a garden, kept as a list of its rows:

Reaching a shelf inside the row works with the same = as any shelf: rows[1] = "kale" replaced the second item. Reaching past the end of a list is refused in plain words that say how many items there are — try say rows[9] in your own copy and read the refusal; it is your first, and it is kind.

Step 2: the toolbox


The toolbox is the set of tools a program calls by name, like functions that were always there. Each is handed values in parentheses and hands one value back. Hand a tool the wrong kind of value and it refuses in plain words, naming the tool and showing how it is called. You have already used two: length, which counts, and append, which adds one item to the end of a list:

Step 3: text, taken apart and put together


Three tools do most of the everyday text work. sorted hands back a new list in order (the list it was given is left as it was). join speaks every item of a list and joins the spoken forms with a separator between them. split is join's way back — it cuts text at every separator and gives back the pieces:

Step 4: a card of facts


An object is the other shape of keeping: values with named fields, written between { }, each field a name, a colon, and a value. plant.name reaches a field, and a field can be given — or given for the first time — with the same dot:





Runs right here, in your browser.




The book says it answers:
yardlong beans
{ name: "yardlong beans", watered: false }
["name", "watered"]




Fields keep the order they were first given, as the spoken form shows, and fieldnames lists them. A list answers "what stands in the row?"; an object answers "what do we know about this one thing?"


Your turn. Make an object for a dog: a name field and an age field. Say the dog's name, then give the dog a brand-new field, good, set to true, and say the whole object.

The ledger grows: gifts with names


Now the amounts from Lesson 2 get their names. Each gift becomes an object — who it went to, how many cents — and the book becomes a list of those objects. A list of objects is how most real keeping is done:

You can now…


  • keep a row of values in a list, reach items by


  number from 0, and replace them;


  • grow a list with append and count it with


  length;


  • sort with sorted, join with join, cut text with


  split, search with find, and take pieces with   part;


  • keep a card of named facts in an object, reach and


  add fields with the dot, and list them with   fieldnames;


  • weave the two together: a list of objects.
